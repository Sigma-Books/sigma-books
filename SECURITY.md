# Politique de sécurité

## Signaler une vulnérabilité
**Ne créez pas d'issue publique.** Utilisez le signalement privé de GitHub :
onglet **Security → Report a vulnerability** du dépôt `Sigma-Books/sigma-books`.

Merci d'indiquer : la version ou le commit concerné, la description, les étapes de reproduction, l'impact estimé.

## Nos engagements
| Étape | Délai |
|---|---|
| Accusé de réception | 3 jours ouvrés |
| Première évaluation | 10 jours ouvrés |
| Correctif des vulnérabilités critiques | aussi vite que possible, objectif 30 jours |

Nous publions un avis de sécurité (GitHub Security Advisory) pour chaque vulnérabilité corrigée et créditons la personne qui l'a signalée, si elle le souhaite.

## Versions prises en charge
Le projet est en construction : seule la branche `main` est prise en charge jusqu'à la version 1.0.

## Programme de bug bounty
Un programme de bug bounty sur la plateforme AarMe est prévu. Il sera annoncé ici.

## Périmètre
Code de ce dépôt et services Sigma Books Cloud. Hors périmètre : déni de service volumétrique, ingénierie sociale, attaques physiques.
