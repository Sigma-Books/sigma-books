# Lot L0 — Fondations du dépôt

> **À donner tel quel à Claude Code** comme première tâche.
> Durée visée : 2 semaines. Aucune logique métier dans ce lot.

## Contexte
Lis d'abord `CLAUDE.md`, `docs/fondations.md` (§3, §7, §8) et les ADR de `docs/adr/`. Le dépôt public est `github.com/Sigma-Books/sigma-books`, licence AGPL-3.0-or-later.

## Objectif
Un dépôt public prêt à recevoir du code métier : workspace Rust compilable, interface squelette, CI de sécurité complète et verte, fichiers de gouvernance, modèle de menaces initial. Chaque tâche ci-dessous fait l'objet d'une branche et d'une PR.

## Tâches

### 1. Workspace Rust
- `Cargo.toml` racine (workspace, `resolver = "2"`), `rust-toolchain.toml` épinglant la **dernière version stable** et les composants `rustfmt`, `clippy`.
- Crates vides compilables : `compta-core`, `syscohada`, `fiscal-sn`, `formats`, `integrite` (lib + binaire `sigma-verifier`), `ia`, `authz`, `api` (binaire), `worker-documents` (binaire). Conserver les `CLAUDE.md` déjà présents.
- `[workspace.lints]` : `unsafe_code = "forbid"`, clippy `all` et `pedantic` en avertissement (bloquants en CI), `unwrap_used`/`expect_used` interdits hors tests.
- `[workspace.package]` : `license = "AGPL-3.0-or-later"`, `edition`, `repository`.
- `rustfmt.toml`, `clippy.toml` si nécessaire.

### 2. Politique de dépendances
- `deny.toml` (`cargo-deny`) :
  - licences autorisées : MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0, MPL-2.0, AGPL-3.0, GPL-3.0, LGPL-3.0 ; tout le reste refusé (notamment « GPL-2.0-only ») ;
  - avis de sécurité (RustSec) : refus ;
  - sources : crates.io uniquement ;
  - doublons de versions : avertissement.
- Mise à jour automatique des dépendances (Renovate ou Dependabot), regroupée et hebdomadaire.

### 3. Interface squelette
- `web/` : SvelteKit + TypeScript strict, `adapter-static`, pnpm avec lockfile, une page d'accueil vide. CSP stricte prévue (pas de script inline).
- `site/` : Astro, une page d'accueil, `public/.well-known/security.txt`.

### 4. CI GitHub Actions (toutes les actions épinglées par **hash de commit**, permissions minimales `contents: read` par défaut)
- `rust.yml` : `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all`, `cargo deny check`.
- `web.yml` : lint, typecheck, build, `pnpm audit --audit-level high` pour `web/` et `site/`.
- `secrets.yml` : gitleaks sur chaque PR.
- `codeql.yml` : analyse CodeQL (Rust, JavaScript/TypeScript).
- `sbom.yml` : génération d'un SBOM CycloneDX (`cargo-cyclonedx`) en artefact.
- `scorecard.yml` : OpenSSF Scorecard (hebdomadaire).
- Préparer (désactivé tant qu'il n'y a pas de version) : build reproductible, signature Sigstore, provenance SLSA.

### 5. Gouvernance et collaboration
Les fichiers suivants sont **déjà fournis** par le kit : les relire, les compléter si nécessaire, ne pas les réécrire.
- `docs/collaboration.md`, `CONTRIBUTING.md`, `SECURITY.md`, `TRADEMARK.md`
- `.github/CODEOWNERS`, `.github/pull_request_template.md`, `.github/ISSUE_TEMPLATE/*`, `.github/dependabot.yml`, `.github/labels.yml`
- `scripts/github/configurer-depot.sh` et les rulesets JSON

À créer :
- `lefthook.yml` : crochets locaux `gitleaks protect --staged`, `cargo fmt --check` et validation du message de commit (Conventional Commits) ; installation décrite dans `CONTRIBUTING.md`.
- Workflow `pr-titre.yml` : vérifie que le titre de la PR respecte Conventional Commits (c'est lui qui devient le message du commit squashé) ; à ajouter aux checks requis.
- `LICENSE` : texte **exact** de l'AGPL-3.0 téléchargé depuis `https://www.gnu.org/licenses/agpl-3.0.txt` (ne pas le réécrire de mémoire).
- `CODE_OF_CONDUCT.md` : Contributor Covenant, version française officielle, téléchargée et non réécrite.
- Catégories GitHub Discussions à proposer dans `docs/github.md` : Questions, Idées, Annonces, Marque et licence.

### 6. Modèle de menaces initial
- `docs/menaces/modele-de-menaces.md` : composants et flux (navigateur, API, PostgreSQL, stockage objet, worker documents, API IA, horodatage), zones de confiance (Fondations §3.3), analyse **STRIDE** par flux, menaces propres à l'IA (injection via document), mesures prévues et lot concerné.
- `docs/provenance/README.md` : format du registre de code porté (projet, fichier, licence, auteurs, commit).
