# 0008 — L'IA propose, l'humain valide

- **Statut :** acceptée — **Date :** 2026-11-12

## Décision
- L'IA écrit **uniquement dans le brouillard**. Aucune écriture n'est validée sans action humaine (seule exception : à-nouveaux générés à partir d'un exercice clôturé).
- L'IA choisit des comptes parmi les candidats du plan du dossier ; elle ne calcule jamais les montants.
- Score de confiance **calculé** par des contrôles déterministes, jamais déclaré par le modèle.
- Contenu des documents traité comme donnée, jamais comme instruction ; sorties validées par schéma.
- Prompts publics ; données d'évaluation réelles privées.
