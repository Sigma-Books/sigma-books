# 0001 — Rust pour le backend et le moteur comptable

- **Statut :** acceptée — **Date :** 2026-11-12

## Contexte
Logiciel comptable public, exigence de sécurité maximale, code produit en grande partie avec des agents IA.

## Décision
Backend, moteur comptable et outils en **Rust** (édition et toolchain stables épinglées). `#![forbid(unsafe_code)]` dans toutes les crates.

## Conséquences
- Sûreté mémoire et de concurrence garanties à la compilation (recommandation NSA/CISA).
- Invariants comptables encodés dans les types ; le compilateur filtre une partie des erreurs des agents IA.
- Binaire unique : déploiement SaaS, instance dédiée et auto-hébergement simplifiés.
- Coût : courbe d'apprentissage, compilation plus lente, recrutement plus difficile ; revues humaines obligatoires sur le moteur.

## Alternatives écartées
Go (types moins expressifs), TypeScript/Node (exposition de la chaîne npm), Java/C# (runtime lourd), Python (typage optionnel).
