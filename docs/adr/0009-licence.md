# 0009 — Licence AGPL-3.0-or-later, CLA, marque réservée

- **Statut :** acceptée — **Date :** 2026-11-12

## Décision
- Code sous **AGPL-3.0-or-later**, publié sur GitHub dès le premier commit.
- Contributions externes sous **CLA** (modèle standard, géré par CLA Assistant) pour préserver une double licence commerciale.
- **Marque « Sigma Books » et logo réservés** (dépôt OAPI après recherche d'antériorité) ; politique de marque dans `TRADEMARK.md`.
- Code porté d'autres projets : uniquement sous licence compatible (GPL-3.0+, LGPL-3.0, AGPL-3.0, licences permissives), avec attribution dans `docs/provenance/`. Code « GPL-2.0 uniquement » exclu.

## Conséquences
Un tiers qui exploite une version modifiée en SaaS doit publier ses modifications. La valeur commerciale repose sur le service (hébergement, IA, mises à jour réglementaires, support) et la marque.
